# 网格记账

人工报成交入账。不拉行情、不下单、不跑回测。

会话里真正缺的是：**报一笔 → 按移动基准价改账 → 落盘，能撤回**。本目录就是这件事。

## 规则（conv 38 B 口径）

- 高抛 `下一基准 = 四舍五入4位(B×(1+上涨步长/100))`，低吸 `下一基准 = 四舍五入4位(B×(1-下跌步长/100))`。步长输入单位为百分比，默认 0.85 / 0.8。
- 所有价格、成交金额、手续费、资金和增益统一按 **四位小数** 计算，每一格使用上一格的四位小数结果继续计算。费率和百分比系数保留原精度，例如买入费率仍为 `0.00008`。
- 显示精度取决于新建账本的初始基准输入：`53.75` 显示两位，`53.755` 显示三位；不足两位补齐，三位及以上显示三位。计算器按自己的起始输入选择显示精度。显示舍入不参与后续计算，点击网格价或重新打开计算器会保留实际的四位小数。
- **基准价只跟触发网格价走，不跟成交价走。**
- 跳格倍数委托：跨几格就做几笔，每格默认 100 股，同一成交价、各自触发价。
- 建仓（例如先卖 3400）不计入买卖笔数；初始持仓可 0 或负。
- 买入费用 `金额×0.008%`，卖出费用 `金额×0.058%`，每格费用四舍五入到 0.0001。例如买入 100 股、成交 53.32：金额 5332.0000，费用 0.4266，总支出 5332.4266。
- 占用资金 = 累计买入支出 − 累计卖出到账（含建仓；为负表示净回笼）。
- 一直持有资产 = 初始持仓 × 现价 + 建仓现金
- 当前实际资产 = 当前持仓 × 现价 + 净回笼现金
- 网格增益 = 当前实际资产 − 一直持有资产

争议（未触及、临界、数量和格数对不上）会先问再记。

价格必须为有限正数，成交股数、单笔股数和触发次数必须为正整数；初始持仓与当前持仓允许负整数。上涨步长须大于 0，下跌步长须大于 0 且小于 100%。不能产生零价格或在四位小数下停滞的网格。非法输入会弹窗、阻止计算及入账，并保留输入供手动修改。

每次最多计算或入账 5000 格，超出时整批拒绝并提示，不截断入账。撤回前会检查可撤回批数，新记录同时保存状态与配置以便恢复步长、单笔股数等；旧记录缺少的历史配置无法补推。建仓改单会同步重算建仓现金和对比基准，调整记录不能当作成交记录改单。

例如上涨 0.85%、触发 5 次：起始 `53.75` 的最终价为 56.0736，显示 **56.07**；起始 `53.755` 的最终价为 56.0788，显示 **56.079**。

## 用法

无第三方依赖。Python 3.11+。默认无净买/净卖限制，持仓和初始持仓都可以是负数。

计算器界面：双击 `网格记账`（快捷方式）或 `启动记账.bat`。不要在编辑器里打开 `ledger.py`，在文件夹里双击即可。

```text
python gui.py
python ledger.py
```

每笔成交自动写入当前存档；右侧列表点击即可切换，纸带在窗口下方。可「另存为」「改名」。点「初始持仓」修改初始持仓（可负），当前持仓按相同差额同步调整，保留已发生的净买卖量和网格增益；一直持有资产和当前实际资产随持仓重算。该调整会自动保存，可用「撤回」同时恢复两项持仓。

底行依次为「不动」「改价」「＋」「－」，四个按钮等大，红色「＋」加价、绿色「－」减价，不再显示「建仓」按钮。「＋」「－」按当前显示成交价的末位小数加减，例如 `53.32 → 53.33`、`53.755 → 53.756`；不足两位小数时按 `0.01` 调整。以屏幕上的价格为起点，不沿用隐藏的小数，只调整待录入价格，不自动成交入账。减到零或负数时提示并保留原值。修改初始持仓请点击左侧「初始持仓」数值。

计算器输入会保存；尚未点「计算」就关闭主窗口，也能在下次打开时恢复。

命令行：

```text
python ledger.py new 实盘 --base 53.75 --shares -3400 --opening-price 53.75
python ledger.py repl
```

```text

python ledger.py list
```

账本在 `books/<名称>.json`。换会话不丢。

旧账本加载时保留已记账的历史金额和费用，不重新计算过去的成交；新成交和主动修改的成交使用四位小数。新存档保存显示位数，旧存档按原始基准推断显示位数。

## 测试

```text
python -m unittest discover -s tests -v
```

`tests/test_conv38.py` 用会话 38 的三笔网格核对（第二笔明确指定触发 52.89）：四位基准 53.3396、持仓 -3300、增益 +46.0561；按两位显示为 53.34、+46.06。`test_regressions.py` 另用独立整数与分数计算核对 150 组随机网格，并验证改单、撤回、输入校验和长跳格；`test_gui_validation.py` 验证错误弹窗、输入保留与计算器状态恢复。
